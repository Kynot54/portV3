I used speech-to-text to capture what the user says and text-to-speech to reply. GPT-4 holds the conversation, and GPT-3.5 classifies it for early signs of dementia, using medical datasets. Data lives in Firestore on Firebase, and an API gateway runs on Google Cloud Run with Cloud Storage.
